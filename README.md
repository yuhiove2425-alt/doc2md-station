# doc2md-station · 변환대

문서를 끌어다 놓으면 **LLM에 그대로 투입할 수 있는 마크다운**으로 바꿔주는 로컬 웹 앱입니다.
한글(.hwp/.hwpx), 워드, 파워포인트, 엑셀, PDF, 텍스트 계열을 한 폴더에서 함께 처리합니다.
설치는 명령 두 줄, 외부 서비스나 API 키는 필요 없습니다.

> **English summary** — A local, single-machine web app that watches a folder and converts
> Korean HWP/HWPX, Office (DOCX/PPTX/XLSX), PDF, and text-family files into Markdown built
> for retrieval pipelines rather than for human eyes: semantic structure (heading levels,
> tables, footnotes, equations) is preserved while running headers, footers, and page
> numbers are dropped. HWPX/DOCX/PPTX/XLSX are parsed straight from their zip+XML
> containers with the Python standard library, so the whole dependency list is Flask,
> pyhwp (plus `six`, which pyhwp needs but does not declare), and pypdf.

---

## 왜 이렇게 만들었나

사람이 읽을 문서를 만드는 도구가 아닙니다. 검색·RAG 파이프라인에 넣을 원문을 만드는 도구입니다.
그래서 판단 기준이 일반 문서 변환기와 다릅니다.

- **머리말·꼬리말·쪽번호는 버립니다.** 시각적으로는 문서의 일부지만, 청크에 섞이면 모든 청크에
  같은 문자열이 반복되어 검색 결과를 오염시킵니다.
- **구조를 살리고 모양은 버립니다.** 제목 레벨·표·각주·수식은 의미를 담고 있어 남기고,
  글자 색·정렬·여백은 남기지 않습니다.
- **모르는 것은 지어내지 않습니다.** PDF의 표처럼 정확히 복원할 수 없는 것은 그럴듯하게
  맞추는 대신 줄글로 둡니다. 틀린 표는 틀린 줄 모른 채 인용되기 때문입니다.
- **실패를 조용히 넘기지 않습니다.** 변환할 수 없는 파일은 무시하지 않고, 이유와 해결 방법을
  남긴 뒤 `변환실패` 폴더로 격리합니다.

## 지원 형식

| 분류 | 확장자 | 처리 방식 | 알아둘 점 |
|---|---|---|---|
| 한글 | `.hwpx` | 직접 파싱 (의존성 없음) | 구조 정보가 가장 온전합니다 |
| 한글 | `.hwp` | pyhwp(`hwp5html`) 경유 | 각주가 원본 변환 단계에서 빠집니다 |
| 오피스 | `.docx` | 직접 파싱 (의존성 없음) | 제목·목록·표(셀 병합)·각주/미주·그림 |
| 오피스 | `.pptx` | 직접 파싱 (의존성 없음) | 슬라이드마다 제목 부여, 발표자 노트 포함 |
| 오피스 | `.xlsx` | 직접 파싱 (의존성 없음) | 시트마다 표 하나, 수식은 저장된 값 사용 |
| PDF | `.pdf` | pypdf로 글자 추출 | 머리말·쪽번호 제거, 표는 줄글이 됩니다 |
| 텍스트 | `.txt` `.md` `.csv` `.tsv` `.html` `.htm` `.json` | 표준 라이브러리 | CP949(euc-kr) 파일도 자동으로 읽습니다 |

`.doc` `.ppt` `.xls`(97-2003)는 읽지 않습니다. 다만 조용히 무시하는 대신
"파워포인트에서 .pptx로 저장한 뒤 넣어주세요" 같은 안내와 함께 실패로 기록합니다.
왜 아무 일도 일어나지 않는지 알 수 없는 상태가 가장 나쁜 상태이기 때문입니다.

오피스 문서를 위해 python-docx나 openpyxl을 넣지 않았습니다. 세 형식 모두 zip 안의 XML이라
표준 라이브러리로 충분하고, 새 팀원의 설치 부담을 늘리지 않는 편이 낫다고 판단했습니다.

## 빠른 시작

```bash
git clone https://github.com/yuhiove2425-alt/doc2md-station.git
cd doc2md-station
pip install -r requirements.txt
python app.py
```

Windows에서는 `run.bat`을 두 번 누르면 됩니다. Python 설치 여부를 확인하고, 필요한 패키지가
없으면 자동으로 설치한 뒤 브라우저를 엽니다.

브라우저에서 `http://127.0.0.1:7800` 으로 접속합니다. 같은 네트워크의 팀원은 콘솔에 함께
출력되는 `http://<사내 IP>:7800` 주소로 각자 접속해 쓸 수 있습니다.

> 요구 사항: Python 3.9 이상. 의존성은 Flask · pyhwp · pypdf 세 개이고, 여기에 `six`가
> 하나 더 붙습니다 — pyhwp가 내부에서 쓰면서도 자기 의존성으로 선언해두지 않아,
> 빼면 `.hwp`만 조용히 실패합니다. 자세한 내용은 아래 "알려진 한계"에 적어두었습니다.
> 처음 확인해볼 때는 `examples/sample-document.hwpx`를 `작업전`에 넣어보세요.
> 제목·표 병합·수식·각주·그림이 모두 들어 있어 전체 흐름을 한 번에 볼 수 있습니다.

### 폴더 구조

첫 실행 때 프로그램 옆에 `작업폴더`가 자동으로 만들어집니다 (저장소에는 포함하지 않습니다).

```
작업폴더/
  작업전/      ← 여기에 변환할 문서를 넣습니다
  작업완료/    ← 변환에 성공한 원본이 옮겨집니다
  변환실패/    ← 실패한 원본이 격리됩니다
  마크다운/    ← .md 결과물과 assets/ 이미지
```

경로를 바꾸려면 첫 실행 후 생성되는 `config.json`의 `root`를 수정하세요.

## 동작 원리

### 폴더 감시

2초 주기로 `작업전`을 확인하되, **파일 크기가 3초간 변하지 않아야** 큐에 넣습니다.
네트워크 드라이브로 대용량 파일을 복사하는 도중에 절반만 읽어 변환하는 사고를 막기 위한
장치입니다. 원본을 옮기지 못하면(다른 프로그램이 파일을 잡고 있는 경우) 결과물을 폐기하고
같은 파일을 다시 잡지 않도록 잠급니다 — 결과물만 쌓이고 원본은 남아 무한 반복되는 상황을
피하기 위해서입니다.

### 형식별 처리

**`.hwpx` · `.docx` · `.pptx` · `.xlsx` 는 바로 처리됩니다.** 모두 zip 안의 XML이라 이
프로그램이 직접 읽습니다. 태그는 네임스페이스를 떼고 **로컬명으로만** 비교하기 때문에,
한컴이나 오피스 버전이 올라가도 잘 깨지지 않습니다.

**`.hwp` 는 pyhwp를 거칩니다.** 바이너리 포맷이라 `hwp5html`을 서브프로세스로 호출해 HTML로
바꾼 뒤 같은 파이프라인으로 재구성합니다. 설정 화면의 명령 입력란(`hwp_to_hwpx_command`)에
다른 변환기를 지정하면 그쪽이 우선합니다.

**엑셀 수식은 계산하지 않습니다.** 마지막으로 저장될 때 캐시된 값을 씁니다. `=SUM(B2:B9)`는
LLM에게 아무 정보도 아니고, 사람이 화면에서 본 값이 문서의 내용이기 때문입니다. 표시 서식이
날짜 계열인 칸만 엑셀 내부 일련번호에서 `2026-08-12` 형태로 되돌립니다.

**PDF는 복원이 아니라 추정입니다.** PDF에는 문단·제목 개념이 없고 글자 좌표만 있습니다.
그래서 세 가지만 규칙으로 처리합니다.

1. 여러 쪽의 같은 자리(위·아래 가장자리)에 반복되는 문구를 머리말·꼬리말로 보고 제거합니다.
   단 제목이나 글머리 기호 모양의 줄은 후보에서 제외해, 장마다 같은 번호 체계를 쓰는 문서에서
   제목이 함께 지워지지 않게 합니다.
2. 줄바꿈으로 잘린 한 문단을 다시 한 줄로 잇습니다.
3. `제3조`, `2.1`, `1.` 처럼 번호로 시작하는 짧은 줄만 제목으로 올립니다.

표는 일부러 복원하지 않고, 쪽 경계는 `<!-- page 3 -->` 주석으로 남겨 나중에 쪽 단위로
인용할 수 있게 합니다. 글자를 거의 찾지 못하면 스캔 PDF로 보고 "OCR이 필요합니다"라는
이유와 함께 실패로 보냅니다.

## 변환 규칙

| 원본 요소 | 마크다운 |
|---|---|
| 개요 수준 / 제목 스타일 | `#` ~ `######` |
| 굵게 | `**텍스트**` |
| 표 (병합 없음) | 파이프 표 |
| 표 (셀 병합 있음) | `<table>` + rowspan/colspan |
| 수식 | `$LaTeX$` 근사 |
| 그림 | `assets/문서명/img1.png` + 참조 |
| 각주·미주 | `[^1]` + 문서 끝 정의 |
| 머리말·꼬리말·쪽번호 | 버림 |

형식마다 추가로 지키는 규칙입니다.

| 형식 | 마크다운 |
|---|---|
| 파워포인트 슬라이드 | `## N. 슬라이드 제목` (제목 개체틀이 없으면 `## 슬라이드 N`) |
| 발표자 노트 | `> **발표자 노트** — …` (설정에서 끌 수 있음) |
| 엑셀 · CSV 시트 | `## 시트이름` + 표 하나, 첫 행은 머리글 |
| PDF 쪽 경계 | `<!-- page N -->` (설정에서 끌 수 있음) |
| 원본이 이미 `.md` | 본문은 그대로 두고 원본 frontmatter만 교체 |
| `.json` | json 코드 블록으로 감싸 정렬 |

### frontmatter

각 결과 파일 앞에는 출처 인용에 쓸 frontmatter가 붙습니다.

```yaml
---
source: "2024_인사규정.docx"
format: docx
converted_at: 2026-08-12T01:44:48
headings: 3
paragraphs: 12
tables: 1
images: 1
footnotes: 0
chars: 390
---
```

`format`은 뒤 단계에서 결과를 쓰는 쪽의 판단 근거입니다 — 예컨대 `format: pdf` 문서는 표가
줄글로 풀려 있을 수 있다고 가정해야 합니다. 쪽·슬라이드·시트 수는 해당 형식에서만 붙고
(`pages` / `slides` / `sheets`), 텍스트 계열에는 읽어낸 인코딩(`encoding`)이 함께 적힙니다.

## 설정

화면 아래 설정 카드에서 바꿀 수 있고, 값은 `config.json`에 저장됩니다.

| 키 | 기본값 | 설명 |
|---|---|---|
| `root` | `./작업폴더` | 작업 폴더 위치 |
| `poll_seconds` | `2` | 폴더 확인 주기(초) |
| `stable_seconds` | `3` | 파일 크기가 이만큼 변하지 않아야 처리 |
| `extract_images` | `true` | 그림을 `assets/`로 꺼낼지 |
| `include_speaker_notes` | `true` | 파워포인트 발표자 노트 포함 |
| `pdf_page_marks` | `true` | PDF 쪽 경계 주석 남기기 |
| `pdf_headings` | `true` | PDF에서 번호로 제목 추정 |
| `sheet_max_rows` | `2000` | 엑셀·CSV에서 옮길 최대 행 수 |
| `hwp_to_hwpx_command` | `""` | 외부 HWP 변환기 명령 (`{input}`·`{output}` 치환) |
| `port` | `7800` | 서버 포트 |

## API

로컬 대시보드가 쓰는 내부 API입니다. 자동화 스크립트에서 그대로 호출해도 됩니다.

| Method | 경로 | 설명 |
|---|---|---|
| GET | `/` | 대시보드 페이지 |
| GET | `/api/state` | 감시 상태, 대기/완료/실패 목록, 로그, 설정, 지원 형식(`formats`) |
| POST | `/api/watch` | `{"on": true\|false}` — 폴더 감시 시작/중지 |
| POST | `/api/scan` | 감시를 켜지 않고 지금 한 번만 스캔·변환 |
| POST | `/api/config` | 설정 일부 갱신 (위 표의 키) |
| POST | `/api/upload` | `multipart/form-data` 업로드 (최대 200MB) |
| GET | `/api/preview?name=파일명.md` | 변환 결과 내용 조회 |
| GET | `/download/<name>` | 변환 결과 다운로드 |

`/api/state`의 `formats`는 화면이 그대로 그리는 데이터입니다. 각 항목에 `available`과
`reason`이 있어서, pyhwp나 pypdf가 없는 환경에서는 그 이유가 화면에 그대로 표시됩니다.

## 코드 구조

```
app.py                 Flask 서버, API 라우트, 설정 로드/저장
core/registry.py       지원 형식 표 (확장자 → 파서). 형식 추가는 여기서 시작
core/convert.py        형식별 파서 선택 → 마크다운 파일 쓰기까지의 공통 흐름
core/markdown.py       구조 → 마크다운 직렬화 (모든 형식이 이 한 곳을 거침)
core/hwpx.py           HWPX 파싱 + 공용 Document/Block/Cell 정의
core/hwp_binary.py     .hwp → pyhwp(hwp5html) → 마크다운용 구조로 재구성
core/ooxml.py          docx/pptx/xlsx 공통 헬퍼 (zip·XML·관계 파일·그림 추출)
core/docx.py           워드 파싱
core/pptx.py           파워포인트 파싱
core/xlsx.py           엑셀 파싱
core/pdf.py            PDF 글자 추출 + 머리말 제거 + 문단 복원
core/plain.py          txt / md / csv / tsv / html / json 처리
core/pipeline.py       폴더 감시, 쓰기 완료 판정, 파일 이동, 상태 관리
templates/index.html   대시보드 화면 전체 (HTML + CSS + JS 단일 파일, 빌드 스텝 없음)
```

설계의 축은 두 가지입니다.

**하나, 모든 파서는 같은 `Document`를 돌려줍니다.** 블록 목록(제목·문단·표·원문) + 각주 +
그림 + 통계로 이루어진 구조이고, 그림 추출·직렬화·파일 쓰기는 `convert.py`가 공통으로
처리합니다. 형식이 늘어도 출력 규칙은 한 곳에서만 바뀝니다.

**둘, 지원 형식 목록은 `core/registry.py`에만 있습니다.** 폴더 감시 대상, 업로드 검사,
파일 선택 필터, 화면의 형식 안내가 모두 이 표를 API로 받아 그립니다. 목록을 두 군데에 두면
"화면에는 된다고 적혀 있는데 아무 일도 안 일어나는" 상태가 반드시 생깁니다.

### 형식 하나 추가하기

1. `core/`에 파서를 만듭니다. `parse(path, cfg)` 하나만 있으면 되고, `Document`를 돌려줍니다.
2. `core/registry.py`의 `FORMATS`에 한 줄 추가합니다.
3. `core/convert.py`의 `_PARSERS`에 이름을 연결합니다.

화면은 고칠 필요가 없습니다. 다음 새로고침 때 새 형식이 칩으로 나타나고, 파일 선택 필터와
업로드 검사에도 자동으로 반영됩니다.

## 알려진 한계

**표 병합은 HTML로 나갑니다.** 마크다운 파이프 표가 병합을 표현하지 못해서입니다. LLM은 HTML
표를 잘 읽으므로 검색 품질에는 문제가 없지만, 순수 마크다운만 받는 파이프라인이라면
`core/markdown.py`의 `_table()`을 셀 단위 문장화로 바꾸세요.

**수식 변환은 근사입니다.** 분수·제곱근·그리스문자·연산자만 LaTeX로 옮기고, 행렬이나 복잡한
중첩은 원본 스크립트가 남습니다. 매핑은 `core/hwpx.py`의 `LATEX_MAP`에 추가할 수 있습니다.

**그림은 추출만 하고 설명이 없습니다.** 도표가 중요한 문서라면 추출된 이미지를 VLM에 넘겨
캡션을 만들어 채우는 단계를 뒤에 붙이는 것을 권합니다.

**제목 인식은 스타일과 개요 수준에 의존합니다.** 스타일을 쓰지 않고 글자 크기만 키워 만든
제목은 제목으로 잡히지 않습니다. 이런 문서가 많다면 크기 기준 추론을 추가해야 합니다
(`core/hwpx.py`의 `StyleTable.heading_level()`).

**`.hwp`(pyhwp 경로)는 `.hwpx`보다 정보가 적습니다.** `hwp5html`이 각주·미주를 버리므로 각주
없이 나오고, 제목도 스타일 이름이 없어 글자 크기 비율로만 추정합니다.

**pyhwp는 `six`를 쓰면서 의존성으로 선언하지 않습니다.** 그래서 `six`를
`requirements.txt`에 직접 넣어두었습니다. 이게 빠지면 설치는 성공하는데 `hwp5html`만
`ModuleNotFoundError: No module named 'six'`로 죽고, 화면에는 "pyhwp가 없습니다"라고
표시됩니다 — 이미 설치한 사람에게는 가장 헷갈리는 안내라 근본 원인 쪽을 막아두었습니다.

**PDF 제목·표는 추정입니다.** 번호 없이 크기만 키운 제목은 본문으로 남고, 표는 복원하지
않습니다. 머리말 제거도 "여러 쪽에 반복되면 본문이 아니다"라는 추정이라, 본문에 같은 문구가
쪽마다 반복되는 문서라면 그 줄이 빠질 수 있습니다. 설정에서 끌 수 있습니다.

**엑셀은 값만 옮깁니다.** 차트·조건부 서식·셀 색은 남지 않고, 시트가 크면 `sheet_max_rows`
까지만 옮긴 뒤 잘랐다는 사실을 결과에 적어둡니다.

## 이전 버전에서 달라진 점

이 저장소는 한글 전용이던 `hwp-md-converter`를 다형식 변환기로 확장한 버전입니다.

- **형식 확장** — 워드·파워포인트·엑셀·PDF·텍스트 계열(`txt`/`md`/`csv`/`tsv`/`html`/`json`)
  추가. 오피스 3종은 새 의존성 없이 표준 라이브러리로 직접 파싱합니다.
- **레지스트리 도입** — 흩어져 있던 확장자 목록(감시·업로드·화면 안내)을 `core/registry.py`
  한 곳으로 모으고, 화면은 API로 받아 그리도록 바꿨습니다.
- **파이프라인 일반화** — 형식별로 중복되던 그림 추출·직렬화·파일 쓰기를 `convert.py`의 공통
  흐름으로 합쳤습니다. 파서는 `Document`만 돌려주면 됩니다.
- **frontmatter 확장** — `format`, `pages`/`slides`/`sheets`, `encoding` 추가.
- **실패 안내 개선** — 옛 형식(`.doc`/`.ppt`/`.xls`), 스캔 PDF, 암호 걸린 PDF를 이유와 해결
  방법이 담긴 메시지로 구분해 처리합니다.
- **화면 개편** — 지원 형식 카드(사용 불가 형식은 이유까지 표시), 파일 목록의 확장자 배지와
  분류별 색, 형식별 옵션 스위치(발표자 노트·PDF 쪽 주석·PDF 제목 추정·최대 행 수)를 추가했습니다.
- **파일명 정리** — 저장소에 커밋되는 파일은 영문명으로 통일했습니다 (`run.bat`,
  `examples/sample-document.hwpx`). 실행 중 만들어지는 작업 폴더 이름은 그대로 한글입니다.

## 저장소에 포함되지 않는 것들

`.gitignore`로 제외했습니다. 클론 후 첫 실행 때 자동으로 만들어지거나, 개인 개발 환경에만
있어야 하는 파일들입니다.

- `config.json` — 첫 실행 시 자동 생성. 커밋된 것을 그대로 받으면 원 개발자의 로컬 경로가
  딸려 와 다른 컴퓨터에서 폴더 생성이 실패할 수 있습니다.
- `작업폴더/` — 실행 중 생기는 런타임 데이터.
- `.claude/` — 로컬 개발 세션 설정(기기별 경로 포함).
- `__pycache__/`, `*.pyc` — 컴파일 캐시.

## 보안 메모

Flask 개발 서버를 `0.0.0.0`에 바인딩해 같은 네트워크에서 접속할 수 있게 되어 있습니다.
인증이 없고 업로드·경로 설정이 열려 있으므로 **신뢰할 수 있는 사내망에서만** 사용하고,
공개 인터넷에는 노출하지 마세요.

파일을 읽는 두 경로(`/api/preview`, `/download`)는 결과 폴더(`마크다운`) 밖으로 나가지
못하게 막아두었습니다. 요청으로 들어온 이름을 폴더 경로에 그냥 이어붙이면 `../`를 섞어
폴더 밖 파일까지 읽히는데, 같은 네트워크의 누구나 부를 수 있는 서버라 실제로 문제가 됩니다.
경로를 정규화한 뒤 결과 폴더 안인지 확인하고, 아니면 404로 돌려보냅니다.

다만 이건 실수로 폴더 밖이 열리는 것을 막는 장치일 뿐 인증이 아닙니다. 사내망에 있는
사람은 여전히 변환 결과를 모두 볼 수 있습니다.
